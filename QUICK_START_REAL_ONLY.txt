### FICHIER 2 : smc_futures/engine/execution/order_manager.py

AJOUTER cette méthode APRÈS execute_signal() (vers ligne 300) :

```python
    # ──────────────────────────────────────────────────────
    #  Hook d'Exécution Publique (Pour Auto-Exec Orchestrateur)
    # ──────────────────────────────────────────────────────

    async def execute(
        self,
        symbol: str,
        signal_dict: Dict,
        signal_id: str,
        executor,
        active_trade: Optional[Dict] = None,
        account_balance: float = 0.0,
    ) -> Dict:
        """
        Méthode d'exécution unique appelée directement par l'orchestrateur
        pour le hook d'auto-exécution.
        
        Retourne :
            {
                "success": bool,
                "entry_order_id": str ou None,
                "quantity": float,
                "price_executed": float,
                "timestamp": str,
                "reason": str (si échec)
            }
        """
        # 1. Pré-vol
        ok, reason, details = self.pre_flight_checks(
            symbol=symbol,
            signal_dict=signal_dict,
            signal_id=signal_id,
            active_trade=active_trade,
            account_balance=account_balance,
        )
        
        if not ok:
            logger.warning(f"[AUTO_EXEC] REJET PRÉ-VOL | {symbol} | raison={reason}")
            return {
                "success": False,
                "reason": reason,
                "details": details,
            }
        
        # 2. Exécution
        logger.info(f"[AUTO_EXEC] PRÉ-VOL OK | {symbol} | exécution en cours...")
        
        quantity = details.get("quantity", signal_dict.get("quantity", 0.001))
        leverage = details.get("leverage", 3)
        
        result = await self.execute_signal(
            executor=executor,
            symbol=symbol,
            signal_dict=signal_dict,
            quantity=float(quantity),
            leverage=int(leverage),
        )
        
        return result
```
