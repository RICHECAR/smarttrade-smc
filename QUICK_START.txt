═══════════════════════════════════════════════════════════════
 DÉPANNAGE
═══════════════════════════════════════════════════════════════

Ordres bloqués avec [REJECT] reason=COOLDOWN_ACTIVE ?
   Attendre 300+ secondes, ou réduire TRADE_COOLDOWN_SEC

Ordres bloqués avec [REJECT] reason=INVALID_TP_SL_GEOMETRY ?
   Vérifier : LONG (SL < entrée < TP), SHORT (TP < entrée < SL)

Ordres bloqués avec [REJECT] reason=MAX_TRADES_PER_DAY ?
   Attendre le reset UTC à minuit, ou augmenter MAX_TRADES_PER_DAY

Aucun ordre exécuté malgré AUTO_EXECUTE_MODE=true ?
   Vérifier les logs pour [REJECT] ou [HTTP_FAIL]
   Vérifier que BITGET_API_KEY est configuré
   Vérifier le statut kill-switch : GET /api/status


Questions ? Consulter :
  1. GO_LIVE_SUMMARY.txt (référence détaillée)
  2. Logs : [REJECT], [EXEC], [HTTP_FAIL]
  3. Statut API : GET /api/status
  4. Kill-switch : POST /api/bot/kill-switch

Prêt ? Commencer à Phase 1 (tests) → Phase 2 (shadow 24h) →
        Phase 3 (live, 1 trade) → Phase 4 (montée en charge)

 Bon trading ! N'oubliez pas : commencez avec MAX_TRADES_PER_DAY=1
